This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Open-data repository by Digital4Better providing geographic and environmental data for calculating digital service footprints. Used by fruggr (www.fruggr.io). Published as `@digital4better/data` on npm.

## Commands

- **Install dependencies**: `yarn --frozen-lockfile`
- **Generate all data + build site**: `yarn build`
- **Generate data only**: `yarn build:data` (runs `ts-node .` which executes `index.ts`)
- **Dev server (site)**: `yarn start` (Vite, serves the `site/` directory)
- **Build site only**: `yarn build:site`
- **Version bump**: `npm version patch` (auto-updates `releaseDate` in package.json via preversion hook)

Node version: 20 (see `.nvmrc`, used by CI via `node-version-file`). Package manager: **yarn 1.x**, pinned via `packageManager` for corepack.

There is no `engines` field on purpose: the published package contains data files only, so build-time requirements must not leak to consumers.

## Architecture

### Data Generation Pipeline (`index.ts`)

Single entry point that fetches external data, computes metrics, and exports CSV+JSON files into `data/`. The pipeline runs sequentially:

1. **`generateClouds()`** — reads cloud provider JSON from `data/cloud/` and exports CSV equivalents
2. **`generateCountries()`** — computes geographic distances (country-to-country, region-to-region, user-to-datacenter) from `data/country/regions.json`
3. **`generateFactors()`** — the main pipeline:
   - Fetches global energy mix data from Ember Climate (monthly + yearly CSVs)
   - Fetches Canadian province data from StatCan (ZIP/CSV)
   - Fetches US state data from EIA API
   - Sanitizes data (fills missing periods by extrapolating from parent regions)
   - Adjusts for energy imports (continent mix blended into country mix)
   - Exports energy mixes and impact factors at all granularities (world/continent/country/subdivision × monthly/yearly × global/green)

### Data Directory (`data/`)

| Directory    | Content                                                              |
|-------------|----------------------------------------------------------------------|
| `cloud/`    | Cloud provider regions, VMs, CPUs, accelerators (AWS, Azure, GCP, Scaleway) |
| `country/`  | Regions, countries, continents, distances                            |
| `energy/`   | Environmental impact per energy source (per kWh)                     |
| `equipment/`| Embodied impacts of ICT equipment manufacturing                      |
| `factor/`   | **Generated** — impact factors per kWh consumed, by region/period    |
| `mix/`      | **Generated** — energy mix ratios by region/period                   |

`factor/` and `mix/` are regenerated by `yarn build:data`. Other directories contain source/reference data.

### Site (`site/`)

React + Vite app for data visualization. Uses MUI for styling. Vite config sets `root: "site"` and `publicDir: "../data"`.

### CI/CD (`.github/workflows/main.yml`)

Runs daily (cron) + on-demand. On `main`: generates data, bumps version if changes detected, publishes to npm, deploys site to GitHub Pages.

## Key Data Concepts

- **Regions** are identified by ISO 3166-1 alpha-2 codes (countries) or `XX-YY` format (subdivisions, e.g. `US-CA`, `CA-QC`)
- **Impact types**: ADPe, AP, CTUe, CTUh-c, CTUh-nc, GWP, IR, PM, WU
- **Green energies**: Bioenergy, Hydro, Solar, Wind. Files suffixed `-green` contain green-only factors
- **Periods**: yearly (`"2023"`) or monthly (`"2023-01"`)
